    Create a Payment¶

    Creates a payment and returns the URL where the customer completes the payment flow.

    Use a stable idempotency key

    Send one unique Idempotency-Key for each intended payment. Reuse the same key when retrying after a timeout, but generate a new key for a new payment.

    Headers

    X-Api-Key-Id string · uuid required

    API key identifier issued for the merchant integration.

    X-Signature string required

    Request signature generated from the HTTP method, request path without query string, raw request body, and timestamp.

    X-Timestamp integer · int64 required

    Unix epoch timestamp in seconds used in the signature base string.

    Additional header

    Idempotency-Key string required

    Merchant-generated key that makes retries safe.

    Constraints: 1-64 printable ASCII characters

    Request body

    application/json

    Payment details and merchant callback destinations.

    reference_id string required

    Payment identifier in the merchant system.

    Constraints: 1-64 characters

    amount number · decimal required

    Amount charged to the customer.

    Constraints: Greater than 0; maximum 2 decimal places

    currency string · enum required

    Three-letter ISO 4217 payment currency.

    Possible values:

    EURGBPUSD
    payment_method_id string · uuid required

    Enabled payment method used to route the payment.

    customer object required

    Customer details used for risk checks and payment processing.
    id string required

    Stable customer identifier in the merchant system.

    email string · email required

    Customer email address.

    callback_url string · uri required

    HTTPS endpoint that receives payment status webhooks.

    return_urls object required

    Merchant pages used after the hosted payment flow.
    success string · uri required

    Destination after a successful customer flow.

    failure string · uri required

    Destination after a failed or cancelled customer flow.

    Responses

    201 Created. Payment created successfully. application/json

    Returns the payment resource and its hosted checkout URL.

    id string · uuid

    Platform-generated payment identifier.

    reference_id string

    Merchant payment identifier supplied in the request.

    status string · enum

    Current payment state.

    Possible values:

    CREATEDPROCESSINGSUCCEEDEDFAILED
    amount number · decimal

    Payment amount.

    currency string

    Payment currency.

    checkout_url string · uri

    Hosted page where the customer completes the payment.

    created_at string · date-time

    Creation time in UTC using ISO 8601.

    updated_at string · date-time

    Most recent update time in UTC using ISO 8601.

    409 Conflict. Idempotency key reused with different request data. application/json

    Returns a structured error with a stable code and request identifier.
